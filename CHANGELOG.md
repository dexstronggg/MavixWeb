# Журнал изменений

Все значимые изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [1.0.0] - 2026-05-30

### Added
- Раздача дистрибутивов борта (`.tar.gz`) и станции оператора (`.exe` / `.AppImage`)
  через API сервера.
- Пользовательская инструкция «Начало работы», включая подготовку Raspberry Pi.
- Ссылка на документацию API (Swagger) в футере.

### Changed
- Auth-aware шапка и CTA для авторизованных пользователей.
- Редизайн схемы «Как это устроено» и блока контактов на лендинге.

### Fixed
- Корректная отдача билдов и понятные сообщения об ошибках скачивания.

## [0.3.0] - 2026-05-25

### Added
- Скачивание дистрибутивов MavixDesktop и MavixBoard из личного кабинета.
- Персистентная сессия и сброс пароля по ссылке.

### Changed
- Linux-сборка станции распространяется как `.AppImage` вместо `.deb`.

## [0.2.0] - 2026-05-17

### Added
- Индикатор надёжности пароля на формах регистрации и сброса.
- Страница настроек со сменой пароля по электронной почте.
- Skeleton-плейсхолдеры, баннер недоступности сервера, плавающее оглавление в документации.

### Changed
- Доработки лендинга: анимированный фон, плавный скролл и появление секций.

## [0.1.0] - 2026-05-16

### Added
- Инициализация проекта: Express-сервер, npm-скрипты, runtime-конфигурация через `/config.js`.
- Дизайн-система Aviation Dark (base, components, layout, pages).
- API-клиент к MavixServer с автообновлением JWT и валидацией.
- Публичный лендинг, формы входа/регистрации/восстановления пароля, личный кабинет
  с пользовательской и технической документацией.
