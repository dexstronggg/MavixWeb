Программы Mavix

Десктоп-клиент для оператора и прошивка для дрона. Установите сначала десктоп, затем прошивку на Raspberry Pi.

MavixDesktop

Приложение оператора · v0.1.0
Stable

Клиент для управления дронами: вход в аккаунт, список ваших дронов, видеопоток с камер, калибровка, настройка битрейта и FPS, поддержка USB-джойстика.

Windows 10+ Linux x64

MavixBoard

Прошивка дрона · v0.1.0
Stable

Сборка для Raspberry Pi с автоматически встроенным идентификатором вашего аккаунта. После установки на дрон он сразу появится в вашем приложении оператора — настраивать ничего не нужно.

Raspberry Pi 4+ Ubuntu 24.04 / RPi OS
Порядок установки: сначала установите MavixDesktop на ПК и войдите в аккаунт. Затем скачайте MavixBoard и установите его на Raspberry Pi командой sudo apt install ./mavixboard.deb. Дрон автоматически зарегистрируется в системе и появится в списке.
