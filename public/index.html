Возможности

Всё, что нужно для удалённого полёта

От захвата видео на дроне до управления джойстиком за тысячи километров — в одном решении.

Видео в реальном времени

Поток с USB-камеры дрона уходит напрямую на ваш ПК через WebRTC peer-to-peer. Кодирование H.264 на аппаратном кодере Raspberry Pi — минимальная задержка и стабильный битрейт.

Защищённая авторизация

JWT-токены с автоматическим обновлением, bcrypt-хеширование паролей, восстановление через email. Дрон знает только свой токен — пароли пользователя на нём не лежат.

Кроссплатформенный десктоп

Приложение оператора работает на Windows, macOS и Linux. Авторизация, живой список дронов, видеопоток, калибровка камеры, переключение битрейта и FPS — всё в одном окне.

Низкая задержка

STUN/TURN-серверы для обхода NAT, оптимизированный pipeline GStreamer, heartbeat-мониторинг WebSocket. Реальный пинг и статус соединения видны в правом углу окна управления.

Стандартные протоколы

Полётный контроллер подключается по MAVLink, команды управления — по CRSF. Поддерживаются стандартные USB-джойстики через pygame с калибровкой и сохранением профилей.

Открытая архитектура

Прошивка дрона, десктопный клиент и сервер — три независимых модуля с чёткими границами. Каждый собирается отдельно: Board в .deb для Raspberry Pi, Desktop в нативный пакет, Server в Docker.

Как это работает

Дрон и ваш компьютер обмениваются данными напрямую

Mavix устанавливает соединение между ними. После этого видео и команды управления передаются напрямую — минуя сервер.

На стороне дрона
Ваш дрон
Снимает видео с камеры и принимает команды управления. На борту установлено приложение Mavix.
На стороне сервера
Сервис Mavix
Проверяет права доступа дрона и оператора. Устанавливает между ними соединение. Видео и команды через него не передаются.
На стороне оператора
Ваш компьютер
Отображает видео с дрона. Передаёт команды джойстика и клавиатуры на дрон.

После того как соединение установлено, обмен данными между дроном и компьютером происходит напрямую — без участия сервера.

О проекте

Открытая платформа удалённого пилотирования

Mavix даёт оператору надёжный канал к дрону независимо от расстояния и сетевых условий: видео идёт без значимой задержки, команды управления — без потерь. Раньше для этого требовалось специализированное оборудование и выделенные радиолинии; Mavix решает ту же задачу через обычный интернет.

В основе системы — открытые отраслевые стандарты: WebRTC для прямой передачи видео и данных, MAVLink для связи с полётным контроллером, CRSF для каналов управления, JWT для авторизации. Любой совместимый дрон, полётный контроллер или джойстик встраивается в систему без модификаций и без проприетарных компонентов.

Платформа разделена на три независимых модуля: бортовой, серверный и клиентский. Каждый обновляется отдельно, не затрагивая остальные. Полная техническая документация и руководство оператора оформлены по ГОСТ 19.402-78 и 19.505-79 и доступны в личном кабинете.
