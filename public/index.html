Возможности

Всё, что нужно для удалённого полёта

От захвата видео на дроне до управления джойстиком за тысячи километров — в одном решении.

Видео в реальном времени

Поток с USB-камеры дрона уходит напрямую на ваш ПК через WebRTC peer-to-peer. Кодирование H.264 на аппаратном кодере Raspberry Pi — минимальная задержка и стабильный битрейт.

Защищённая авторизация

JWT-токены с автоматическим обновлением, bcrypt-хеширование паролей, восстановление через email. Дрон знает только свой токен — пароли пользователя на нём не лежат.

Кроссплатформенный десктоп

Приложение оператора работает на Windows, macOS и Linux. Авторизация, живой список дронов, видеопоток, калибровка камеры, переключение битрейта и FPS — всё в одном окне.

Низкая задержка

STUN/TURN-серверы для обхода NAT, оптимизированный pipeline GStreamer, heartbeat-мониторинг WebSocket. Реальный пинг и статус соединения видны в правом углу окна управления.

Стандартные протоколы

Полётный контроллер подключается по MAVLink, команды управления — по CRSF. Поддерживаются стандартные USB-джойстики через pygame с калибровкой и сохранением профилей.

Открытая архитектура

Прошивка дрона, десктопный клиент и сервер — три независимых модуля с чёткими границами. Каждый собирается отдельно: Board в .deb для Raspberry Pi, Desktop в нативный пакет, Server в Docker.

Архитектура

Три компонента, один протокол

Сервер занимается только сигнализацией и авторизацией. Видео и команды управления идут напрямую между дроном и оператором.

Board · на дроне
MavixBoard
Raspberry Pi с USB-камерой и полётным контроллером. Кодирует видео, ретранслирует команды по MAVLink.
WebSocket JWT
Server · сигнализация
MavixServer
FastAPI: авторизация, регистрация дронов, обмен SDP/ICE, выдача STUN/TURN. Медиа через него не идёт.
WebSocket JWT
Desktop · оператор
MavixDesktop
PySide6 на ПК: видеоокно, джойстик, телеметрия, калибровка камер и битрейт на лету.

После handshake Board и Desktop устанавливают прямое WebRTC-соединение — видео и команды управления идут P2P, минуя сервер.

О нас

Команда инженеров и разработчиков

Mavix создаётся командой, которая объединяет опыт в системном программировании, компьютерном зрении и встраиваемых системах. Мы решаем конкретную задачу: дать оператору надёжный канал к дрону независимо от расстояния и сети, не жертвуя задержкой и качеством видео.

Проект построен на открытых стандартах — WebRTC, MAVLink, CRSF, STUN/TURN — и состоит из трёх модулей с чётким разделением ответственности. Это позволяет независимо обновлять прошивку дрона, десктопный клиент и серверную часть без рискованных миграций.

Документация ведётся по ГОСТ 19.402-78 и 19.505-79: техническое описание и руководство оператора для каждого компонента доступны в личном кабинете.
