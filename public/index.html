Возможности

Всё, что нужно для доставки грузов дронами

От создания заявки администратором до сброса груза дроном по координатам — в одном решении.

Заявки на доставку

Администратор создаёт заявку с точкой назначения на карте и описанием груза. Система предлагает её оператору, а после принятия — дрон везёт груз и выполняет сброс по координатам.

Защищённая авторизация

JWT-токены с автоматическим обновлением, bcrypt-хеширование паролей, восстановление через email. Дрон знает только свой токен — пароли пользователя на нём не лежат.

Приложение оператора

MavixDesktop работает на Windows и Linux. Оператор входит под выданными администратором учётными данными, принимает заявки и следит за полётом дрона до сброса груза.

Связь без потерь

STUN/TURN-серверы для обхода NAT, heartbeat-мониторинг WebSocket. Статус дрона и доставки обновляется в реальном времени — оператор и администратор всегда видят актуальное состояние заявки.

Стандартные протоколы

Полётный контроллер подключается по MAVLink, команды управления — по CRSF. Поддерживаются стандартные USB-джойстики через pygame с калибровкой и сохранением профилей.

Открытая архитектура

Прошивка дрона, десктопный клиент и сервер — три независимых модуля с чёткими границами. Каждый собирается отдельно: Board в .deb для Raspberry Pi, Desktop в нативный пакет, Server в Docker.

О проекте

Открытая платформа доставки грузов дронами

Mavix автоматизирует доставку малогабаритных грузов дронами: администратор формирует заявку с точкой назначения, система назначает её дрону и оператору, а доставка и сброс груза выполняются по заданным координатам. Связь с дроном работает через обычный интернет, без специализированного оборудования и выделенных радиолиний.

В основе системы — открытые отраслевые стандарты: WebRTC для прямой передачи видео и данных, MAVLink и CRSF для связи с полётным контроллером (ArduPilot, PX4, Betaflight, iNav), JWT для авторизации. Любой совместимый дрон, полётный контроллер или джойстик встраивается в систему без модификаций и без проприетарных компонентов.

Платформа разделена на три независимых модуля: бортовой, серверный и клиентский. Каждый обновляется отдельно, не затрагивая остальные. Полная техническая документация и руководство оператора оформлены по ГОСТ 19.402-78 и 19.505-79 и доступны в личном кабинете.
