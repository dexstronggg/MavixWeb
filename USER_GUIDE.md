# MavixWeb — Руководство администратора

Документ составлен по ГОСТ 19.505-79 «Руководство оператора» (ЕСПД; основной
пользователь веб-кабинета — администратор системы).

## 1. Аннотация
Руководство администратора по работе с веб-кабинетом MavixWeb системы доставки
грузов дронами Mavix.

## 2. Назначение программы
Кабинет позволяет администратору управлять операторами и дронами, создавать
заявки на доставку и просматривать журнал доставок.

## 3. Условия выполнения программы
- Современный браузер; интернет (для карты/геокодирования).
- Учётная запись администратора (регистрация на сайте).

## 4. Выполнение программы

### 4.1 Регистрация и вход
Зарегистрироваться/войти как администратор. После регистрации доступен
`enrollment_token` для подключения бортов.

### 4.2 Операторы
Раздел «Операторы»: создать оператора (ФИО, паспорт, адрес) — логин и пароль
генерируются автоматически и выдаются оператору. Список и удаление.

### 4.3 Дроны
Раздел «Дроны»: список зарегистрированных бортов (борт регистрируется сам через
enrollment), удаление.

### 4.4 Заявки на доставку
Раздел «Доставки»: создать заявку — выбрать дрон, указать адрес/координаты или
**точку на карте** (адрес подставится автоматически), при необходимости описание
груза. Заявка рассылается операторам; первый принявший ведёт доставку.

### 4.5 Журнал
В журнале видны заявки со статусами: `offered` (предложена), `accepted`
(принята), `in_flight` (в полёте), `delivered` (доставлена), `cancelled`
(отменена). Записи сохраняются даже после удаления дрона/оператора (снимки).

### 4.6 Скачивание ПО
Раздел «Скачать»: дистрибутив борта (tar.gz) и приложение оператора
(Windows .exe / Linux .AppImage).

## 5. Сообщения администратору
- Пустой кабинет / выход из аккаунта → сессия истекла, войти заново.
- Карта не загружается / адрес не определяется → проверить интернет (тайлы OSM,
  сервис Nominatim).
